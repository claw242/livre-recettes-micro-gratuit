# Livre des recettes et registre des achats — modèles CSV gratuits (micro-entreprise)

*Loupe & Lettres — créé avec l'aide de l'IA.*

Deux fichiers CSV vides à ouvrir dans Excel, LibreOffice ou Google Sheets :

- `livre-des-recettes-exemple.csv` : numéro, date d'encaissement, référence de la pièce, client, nature, mode de règlement, montant, observations.
- `registre-des-achats-exemple.csv` : mêmes colonnes avec le fournisseur et la date de paiement.

Les 3 lignes d'exemple (fictives) sont à effacer. Séparateur point-virgule, montants avec virgule décimale, dates `AAAA-MM-JJ`.

## Quelques repères

- Le livre des recettes sert à noter chronologiquement les sommes encaissées. Le registre des achats concerne surtout les activités de vente de marchandises ou de fourniture de logement.
- Le format (papier, tableur, logiciel) n'est pas imposé ; les justificatifs se conservent, avec les écritures, selon les règles en vigueur.
- Ces CSV modifiables sont des supports de préparation : ils ne garantissent pas l'inaltérabilité des écritures d'un registre obligatoire (service-public.fr précise que les écritures enregistrées ne peuvent plus être modifiées).
- Les informations officielles et un modèle gratuit se trouvent sur service-public.fr (fiche F23266). Ce dépôt ne remplace ni ces informations ni un expert-comptable.
